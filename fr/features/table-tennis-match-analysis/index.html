Tennis de table · Analyse de match

Reliez les chiffres à votre match de tennis de table.

Filmez votre rencontre depuis une position fixe, puis importez la vidéo complète dans SportArc. Consultez les placements, les statistiques de frappe et le rapport écrit pour revenir sur le match avec votre vidéo.

Lire les données avec la vidéo

L’Analyse de match (Match Review) part de votre rencontre filmée. Les placements, les statistiques de frappe et le rapport écrit vous donnent des éléments à rapprocher des échanges que vous venez de jouer.

Repérez les situations dans les chiffres

Consultez les données de frappe et de placement, puis revenez à la vidéo pour examiner les séquences concernées. Une statistique prend son sens avec le déroulement du point.

Préparez la discussion après le match

Le rapport écrit réunit des observations sur la rencontre. Confrontez-les à la vidéo pour choisir les situations à revoir avec votre entraîneur ou votre partenaire.

Installez une caméra fixe avant la rencontre

La caméra doit garder la même position pendant le match. Placez-la selon le guide afin que la balle, la table et les joueurs des deux côtés restent visibles. Vérifiez le cadre avec une courte prise avant de lancer l’enregistrement complet.

De votre rencontre au compte rendu

  1. Importez la rencontre

    Choisissez le tennis de table et l’Analyse de match, puis importez la vidéo depuis Photos ou Fichiers.

  2. Lancez le traitement

    Attendez l’envoi de la vidéo et suivez les indications de l’app pour démarrer l’analyse.

  3. Précisez le déroulement

    Indiquez les changements de côté et votre position de départ lorsque l’app vous le demande.

  4. Revenez sur le match

    Consultez les placements, les statistiques et le rapport en les rapprochant de la vidéo.

Avant de commencer

Les réponses aux questions sur votre vidéo et les résultats.

Est-ce une application pour consulter mon classement FFTT ?

Cette fonction analyse votre propre vidéo de match. Elle ne consulte ni ne synchronise votre classement fédéral ou vos résultats officiels.

Puis-je analyser un match de tennis ou de badminton ?

L’Analyse de match présentée ici prend actuellement en charge le tennis de table. Pour obtenir des clips de tennis ou de badminton, choisissez le Montage auto.

Pourquoi la caméra doit-elle rester fixe ?

L’Analyse de match demande une prise de vue stable depuis l’angle indiqué dans le guide. Une caméra déplacée pendant la rencontre ne respecte pas ces conditions d’entrée.

Quelle différence avec le Coach IA ?

L’Analyse de match porte sur une rencontre et ses données. Le Coach IA examine une action prise en charge, avec un mouvement en 3D et un retour technique.

Sur quels appareils utiliser SportArc ?

SportArc est disponible sur iPhone et iPad. L’app se télécharge gratuitement et propose des achats intégrés. Consultez les limites d’utilisation et les options Plus dans l’app.

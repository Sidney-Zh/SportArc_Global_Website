乒乓球短发球：用第二跳练好长度与高度

练习乒乓球短发球，先看球在对方台面的第二跳能否留在台内，再控制过网高度，逐步加入落点和接发球练习。

球第一次落在对方网前，看起来已经很短，接着却一路向前，从球台端线掉了下去。下一次发球，你把力量收得更小，球又挂在网上。一直在这两种失误之间来回，很容易不知道该先改哪里。

这组乒乓球短发球练习，把长度和高度分开观察。先选一种熟悉的发球，不安排接球，让球完整弹跳；看清第二跳后，再加入目标区和接发球同伴。准备一张球台和几个球，每次都留一点时间看完球的运行。

从第一球开始保留合法发球流程

将球放在静止、张开的非持拍手掌上，近乎垂直向上抛起，不主动给球加旋转。球离开手掌后至少上升16厘米，在下降过程中击球。触球前，球应一直位于台面之上、端线之后，并让接球方看得见；抛球后及时把非持拍臂移出球与球网之间的空间。

球必须先在己方台面弹跳，再落到对方台面。双打时，这两次落点都要位于相应的右半区。独自练习也保持这个流程，不用降低抛球或遮挡触球的方式解决短发球难题。

每次发球前先站稳、准备好，不必急着把一盆球发完。起始流程相近，前后结果才容易比较，也更方便把练习带进比赛。

看对方台面的第二跳

检查短发球长度时，可以先不接球，观察它是否会在对方台面上再弹第二次，之后才离开球台。这里的“第二跳”只数对方半台：完整过程是己方一跳、对方两跳，也就是整次发球的第三次台面接触。

第一落点靠近网，并不能证明球足够短，要继续看后面的运行。同样，球虽然短，也可能过网太高，让对手有机会进攻。所以长度和过网高度要分开记录。

己方第一跳的位置可以作为调整线索，但它不能独自决定结果。触球高度、方向、速度和旋转也会改变球路。练习开始时，先固定一种熟悉的发球和一个方向。

练习一：让球完整弹跳

练习目的：不依赖接球方的反应，自己辨认发球长度。

  1. 不安排接球，发球后让球继续弹跳。
  2. 观察对方台面的第二跳是否仍留在台上。
  3. 另外记录球是低平过网，还是明显冒高。
  4. 先发一小组，例如五个球，再选择一个地方调整。

五个球只是便于暂停和比较的示例，不是必须完成的训练量。可以一组结束后再捡球，让注意力留在同一种发球上，不急着换动作。

如果球总是出台，稍微减少向前送球的力量，同时保持干净触球。如果接下来开始下网，先检查球路和触球一致性，不要马上恢复成更用力的一拍。目标是找到能重复的合适范围。

练习二：加入明确的落点区域

练习目的：在发短的同时，让方向有计划。

  1. 利用球台现有线条作参照，在对方半台选一个较大的目标区。
  2. 保持原来的发球，不同时增加新的旋转变化。
  3. 发向目标后继续观察，既看第一落点，也看下一跳。
  4. 第一落点进入目标区、随后仍满足短球长度检查，才算完成这次任务。

目标区先留宽一些，方便看出规律。过早瞄准极小的点，可能让每球都像失败，反而忽略长度已经逐渐稳定。

练乒乓球短发球时，同时改变落点、速度和旋转，很难知道哪项调整起了作用。先把这一个任务练清楚，能说出最常见的失误，再调整与它最相关的一处细节。

练习三：让同伴开始接发球

练习目的：有人准备接球时，仍能保留熟悉的发球。

  1. 请同伴正常接发球，你继续保持同样的短球意图。
  2. 沿用上一组练习的准备动作和目标区。
  3. 看发球飞行与回球结果，再准备下一次发球。
  4. 几次有人接球的练习后，穿插几次不接球的长度检查。

球一旦被接回，就看不到原本的第二跳，因此不能完全用回球结果代替长度检查。同伴可能把一只不错的发球接好，也可能对一只偏松的球失误。把回球当作补充信息，不用每一次丢分来判定发球失败。

如果有人接球后你开始赶动作，先回到第一组的稳定准备。让熟悉的发球保留下来，再逐渐增加压力。

让修正对应实际失误

短，但冒高：在保留足够向前运行的同时调整过网高度。简单地把力量全部收掉，可能让球还没过网就落下。

低，但出台：保持触球和方向，重点调整长度。用第二跳检查稍小的向前力量是否有帮助。

频繁下网：先检查过网余量和触球一致性，再考虑增加旋转。基本球路还不稳定时，动作越复杂越难判断。

每球结果都不同：回到一种发球、一个目标和不赶时间的准备。先比较一组，再做下一处调整。

下次训练保留一个重点

最后用最初那种发球结束乒乓球短发球练习，比较过网高度和对方台面第二跳。把最有帮助的一项调整留到下次：可能是更稳定的准备、更低的球路，也可能是更可靠的长度。先有一只自己能辨认、能重复的发球，再发展落点和变化。

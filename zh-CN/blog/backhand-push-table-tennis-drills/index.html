反手搓球总冒高？先把这三个练习做好

反手搓球一会儿冒高、一会儿下网，先别急着加转。从固定下旋来球开始，用三个练习分别检查拍面、弧线和落点，让下一板更有准备。

短球接回去了，却高高地飘到对面，正好给对手上手。下一球赶紧把拍面压低，又直接下网。每一板都换一种动作，反而更难知道问题出在哪里。

这套练习适合正在用横拍学习处理下旋的球友。练反手搓球，可以先把来球固定下来：旋转差不多、落点差不多，一次只检查一个地方。先能稳定接回下旋，再逐步压低弧线、调整落点，比一开始就追求又短又转更容易找到感觉。

先分清搓球和反手拨球

搓球通过摩擦球的下部处理下旋，和反手拨上旋球的动作不同。练习时，先请同伴连续送出轻而稳定的下旋球；如果用发球机，也先固定旋转和落点。不要把不同旋转混在一起，再用同一套拍面去接。

拍面适当打开，在身前留出触球空间，用小幅度动作向前送、摩擦球的下部，随后还原。这里的“送”不是把球托在拍上，也不是突然向前戳一下。

球短，先靠近；动作不用放大

双膝微屈，握拍保持放松。短球够不到时，先移动身体靠近来球，不要站在原地把胳膊伸到底。具体上哪只脚，要结合球的落点和自己的站位，不必每一球都套同一种脚步。

引拍保持小一些。想回短球，可以练习在球弹起后的较早阶段触球，但不需要刻意把球拍抬到每个来球的最高点以上。准备位置应当方便摩擦球下部，而不是逼自己做一个大幅度向下砍的动作。

练习一：固定来球，找到能接回去的拍面

练习目标：面对同一种下旋，找到能连续接回的拍面和触球位置。

  1. 请同伴一球一球送到反手位，尽量保持相近的旋转和长短。
  2. 先朝对面一块宽松的区域搓回去，留出过网余量，不急着贴网。
  3. 每次击球后恢复站位。以五球为一组，记一下失误主要是冒高、出界，还是下网。
  4. 一次只改一点。例如相同来球连续下网，可以试着稍微打开拍面，再比较下一组。

五球只是方便比较，并不是达标线。如果同伴送来的球变化明显，先重新送一组，不要把每次失误都归到自己的动作上。

练习二：降低弧线，同时保住落台

练习目标：减少冒高，又不把过网余量全部挤掉。

  1. 来球保持不变，落点仍然选一块较大的区域。
  2. 请同伴观察过网高度，自己专注于在身前完成触球。
  3. 如果连续冒高，可以分别试试减少向上托的动作，或把拍面稍微收一点。两者不要同时改。
  4. 再比较一组。只有仍然能稳定落台，才保留这个调整。

低不等于短。想检查回球是否够短，可以让对方不接，观察球的第二跳能否仍留在对方台面。这个方法用于判断长短，不代表每一板都必须摆短；压低弧线、落点明确的长搓也有价值。

练习三：确定落点，搓完及时还原

练习目标：知道自己往哪里回，也能准备接下一板。

  1. 保持同一种来球，选对面反手半台或中路较宽的区域作为目标。
  2. 连续几球朝同一区域回，尽量保留前面找到的小幅度动作。
  3. 如果上步进台，击球后及时退出，并把球拍恢复到准备位置。
  4. 下一组再换落点。熟悉后，请同伴多回一板可控的球，检查自己能否来得及衔接。

落点变化和旋转变化分开加。之后可以请同伴提前说明下一组是更转还是更弱的下旋，分别找回稳定的接法，再逐渐练不提前提示的变化。

看清失误，再决定改哪里

连续下网，先检查来球是不是更转、触球是不是太晚或离身体太近。在同一种来球下，小幅打开拍面可能有帮助，不必一下子改成大幅度向上捞。

连续冒高或出界，检查拍面与向上托的幅度，也看看来球是否变成了弱下旋。不要只模仿对手球拍的角度；对方的触球方式与球的飞行同样需要判断。

左右偏得明显时，先把侧旋从基础练习中拿掉。面对右手球员，也不能统一要求每一球都碰球的右侧，要看实际旋转方向。

练完留下一条有用的提醒

结束前，再用最初的固定来球试一组。比较几次回球的高度和落点，不只看最好的一板。把这次最有帮助的一个提醒记下来，比如“短球先靠近”或“收短结束动作”，下次从这里接着练。

网球接发球练习：先把球接回去，再衔接下一拍

用三个网球接发球练习调整准备姿势、紧凑引拍和回球目标。从固定落点开始，再增加方向选择与下一拍，逐步减少接发时的仓促感。

平时底线对拉还算从容，对方一发球，同样的正手却突然来不及了。球已经到身边，球拍还没准备好；平时用得顺的完整挥拍，也变得很难做完。接发球首先要解决的，是给自己留出合适的击球空间和准备时间。

这组网球接发球练习适合已经能够对拉、也能控制发球速度的单打球友。找一位能重复发出较容易来球的搭档，先练一个已知落点，再加入方向选择，最后接上下一拍。练习目标是带着平衡和明确线路进入相持，不必每次接发都直接得分。

让准备姿势真正帮助启动

站在能照顾主要发球方向、又方便留出击球距离的位置。膝盖自然弯曲，球拍准备在身前。等待时采用与你平时正反手转换习惯相配合的握拍方式，让两侧都能及时调整；不同正反手组合，并不一定适合完全相同的等待握拍。

配合对方击球节奏做一个小幅分腿垫步，让自己看出来球方向后能够从稳定的支撑状态启动。不需要跳很高，也不要僵硬地落地。如果对方还没击球，你就早早完成垫步、重新站死，反而还得再启动一次。

接发站位要根据实际来球调整。速度更快的球可能需要多留一些空间，较慢的球则可能允许你靠前一点。每次小幅改变，再接同样的发球比较。不要因为别人站在底线后某个距离，就认为自己也必须照搬。

来球快时，先缩短准备动作

接发球不一定有时间完成慢速底线对拉时的完整引拍。及时转体，把球拍组织到合适的位置，减少不必要的大幅绕拍。手臂与身体保持配合，不是把两条胳膊夹死在身上。

等球落地弹起，在身前留出合适的击球空间，把球送向目标，再自然随挥。动作紧凑，仍然包括准备、触球和随挥，不是把一把不动的球拍伸出去碰运气。

这里的“等球落地”不能省略：接发球不能截击。遇到弹得高的发球，应通过站位或落地后的击球时机调整；在发球尚未落地时直接击球，会失掉这一分。

练习一：固定发球方向，固定回球目标

练习目的： 暂时不用猜落点，把准备和击球先连起来。

  1. 请搭档用容易处理的速度，发向发球区内一个事先约定的位置。
  2. 从准备姿势开始，配合对方发球动作完成小幅分腿垫步。
  3. 等球落地后，用紧凑动作回向场内一块较大的目标区。
  4. 接完这一球就停下，重新准备；重复一小组后再换边。

目标要适合来球方向。面对追身球或靠近中线的发球，可以先回向对面中路的大范围区域。面对外角发球，舒服地回斜线通常比强行变直线留有更多余量。两种目标都要离边线留出空间。

一小组之后，找最先出现的问题。如果总被球挤住，先检查人与球的距离；如果球到了，拍子还在向后走，就简化引拍。为了把动作练清楚，让搭档暂时降低发球速度，是有效的调整。

练习二：保持速度，改练两个落点

练习目的： 根据真实来球选择移动方向，而不是背熟一个固定步法。

  1. 约定两个发球位置，例如一个偏外角、一个更靠近身体，由发球方选择。
  2. 速度保持与第一个练习相近。
  3. 看清来球，调整脚步，选择适合该方向的回球目标。
  4. 每次接完都重新准备，既比较失误，也比较判断和选择。

这一步先增加落点的不确定性，不要同时把发球速度提到最大。否则网球接发球练习很容易变成双方都无法控制的抢球。等练习能够顺畅进行，再增加速度。

也不要只看抛球就完全扑向一侧。可以留意对方的习惯，但击球后仍要继续看球。这组练习要练的是利用实际信息启动，而不是越早猜方向越好。

练习三：接发之后，再打一拍

练习目的： 把接发球与后续相持的位置联系起来。

  1. 继续采用可控的发球速度和较大的回球目标区。
  2. 完成接发，根据自己的回球方向调整位置。
  3. 请发球方回一拍可控的球，你再接一拍。
  4. 到这里结束这一组球，按约定数量练习后交换角色。

现在不只看接发有没有过网，还要看自己是否站得稳、来得及准备下一拍。为了追求边线而失去位置，未必比稳稳回到大范围区域更有用。能进入下一拍的接发球，才真正帮你开始了这一分。

如果实际来球确实较慢、留给你的时间更多，可以采用更完整的挥拍，但仍要保留明确目标。不要把“二发”直接等同于“容易进攻的球”，应根据速度、弹跳和自己拥有的时间作判断。

留下一个能重复做到的提示

结束这次网球接发球练习时，再回到最初那个已知落点。比较一下，自己的准备和击球距离是否比开头更从容。留下一个有效提示，例如早点完成准备，或减小引拍幅度，下次先把它重复出来，再增加发球速度。

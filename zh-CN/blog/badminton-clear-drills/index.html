羽毛球高远球打不远？三个练习找回顺畅发力

用三个练习理顺正手高远球的准备、击球和回位，把球打深，也给下一拍留出时间。

明明已经很用力，球还是落在中场。再打一拍，手握得更紧，肩膀也越来越累，高远球却没远多少。

遇到这种情况，先把来球放简单一点，看看自己在哪里碰到球。击球点已经落到身后时，一味加力往往只会更别扭。下面三个练习，先帮你把正手高远球的动作顺起来。

先练一种高远球

这次练的是正手头顶高远球：把球打得较高，送向对方后场，给自己留出调整时间。暂时不追求又平又快的进攻性平高球，也不混练反手高远球。

需要一位能稳定喂球的球友，以及上方、周围都有足够空间的场地。刚开始不一定非要站到底线。缩短一点击球距离，让动作做得顺，比每球都憋着劲够到底线更合适。

先准备好，再把球送出去

握拍用自然的正手握法，不要把拍面平着端在前面。看见来球后，尽早侧身、举拍，脚步调整到能在高处、稍靠身前击球的位置。

以右手持拍为例，准备时右侧身体通常离球网更远，左臂抬起帮助判断来球和保持平衡。左手持拍则左右相反。不要等球快落到头顶了，才开始往后抬拍。

挥拍有点像顺畅地向前上方投掷，腿、躯干和手臂共同参与。前臂的转动也是其中一部分，不是只靠手腕猛甩一下。

击球时向高处自然伸展，但不用把肘关节顶死，也不要靠明显后仰去够高度。球已经落到身后，就把下一次喂球放慢，或者调整起始位置，别强行复制一个勉强救球的动作。

打完让球拍自然随挥，身体重新站稳。初学时不必加起跳，也不必为了“像高手”刻意做很大的换腿。

练习一：不击球，先把准备和收尾接起来

练习目标：能够顺畅举拍、挥拍，并在结束后恢复平衡。

  1. 找一块空场地，确认球拍不会碰到人或墙。
  2. 从准备姿势开始，转入正手头顶击球的侧身姿势，小幅调整脚步。
  3. 朝想象中位于高处、稍靠身前的击球点，轻松做一次挥拍。
  4. 顺势完成随挥，回到能继续移动的准备姿势。做几次就停下来，检查动作有没有越来越僵。

这不是练腿部极限力量。膝盖不用蹲到最深，更不用憋到发抖。手臂也不用猛甩、硬停。结束后站不稳，就先缩小动作、放慢速度。

让球友从侧面看一看：你想象中的击球点是不是留在身前？这个反馈，比纠结某个角度是不是恰好九十度更有帮助。

练习二：用舒服的距离找击球点

练习目标：在稳定喂球下，把球比较干净地打向后场。

  1. 从自己不费力也能完成动作的位置开始，必要时往前站一点。
  2. 请球友把球高高送到你的正手击球区域，落点尽量一致，给足准备时间。
  3. 提前侧身举拍，调整脚步，在高处、稍靠身前碰球，先瞄准对方后场一个大区域。
  4. 每球之间留一点间隔。检查击球是否顺畅、结束后是否平衡，再接下一球。

可以五个球一组，打完一起看落点。这个数量只是方便复盘，不是训练标准。捡球前先停球，别让散落的球留在脚边。

如果大部分球都明显偏短，先缩短距离，保持轻松的动作。等击球更稳定，再逐步往后移。不要每退一点，就只能靠更紧的握拍和更大的后仰完成。

练习三：打深以后，还要接得上下一拍

练习目标：把高远球和回位连起来，而不只是完成一次击球。

  1. 先保持稳定喂球，约定一个较大的后场目标区，深度以你能够自然打到为准。
  2. 打完就准备回位，不要一直站在原地看球飞到哪里。
  3. 单球稳定后，尝试短回合的合作高远球对打。双方以把球喂舒服、让回合继续为主。
  4. 来球一旦让你来不及准备，就停下重来，不要把整组练习变成连续救球。

先延长回合，再增加速度。如果对方每球都要追着跑，退回单球练习，把落点范围放宽一点。

回位也不是每次都冲到同一个点。合作练习可以约定一个便于接下一球的准备区域；真正比赛时，还要结合自己打出的球和对方可能的回球方向调整。

球还是短，优先看什么？

碰球位置落在身后：提前准备，或者让喂球慢一点。加力不能稳定解决击球太晚的问题。

从头到尾攥着拍柄：两球之间主动放松，留意自己是不是球还没来就已经握紧。能控制球拍就好，不必一直用力。

像举着手臂往上推：先回到轻松的徒手挥拍，再从较短距离试球。一直找不到舒服的头顶动作，可以请教练现场看一下。

打远了，但人也歪了：先保留原来的距离。深度增加了，却来不及接下一拍，还不算把这项技术练完整。

如果肩、肘出现疼痛，就停下来，不要靠加次数或加负重硬练过去。

不只看最远的那一球

连续看几次尝试：短球是不是大多击球偏晚？有没有提前侧身举拍？打完能不能站稳、准备下一拍？

选一个问题带到下次练习里。“早点举拍”能告诉你下一球该做什么；只有“再用点力”，往往找不到球为什么短。

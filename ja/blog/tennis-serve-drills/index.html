テニスのサーブ練習：トスと狙いをそろえる3つのドリル

トス、小さく無理のない準備動作、広い目標を使い、サーブの結果を振り返りやすくする練習です。

かご一杯のサーブを打って、気持ちよく入った2球だけが記憶に残る。ほかはネット、オーバー、追いかけて打ったトスが混ざり、原因がはっきりしません。同じように全力でもう一かご打っても、疑問が残ることがあります。

このテニスのサーブ練習では、それぞれの段階に分かりやすい課題を設けます。対象は、サーブを安定させたい成人の初心者や一般プレーヤーです。コートを片づけて軽く始め、サーブが飛んでくる方向でボール拾いをしないようにしてください。

同じ握りと構えをつくる

一般的な頭上からのサーブを身につける土台として、コンチネンタルグリップが役立ちます。右利きでは、人さし指の付け根の関節をグリップの第2面に置くのが基本で、左利きは左右を逆に考えます。面の番号が分かりにくい場合は、反対側から撮った写真で推測するより、コーチに握りを確認してもらいましょう。

狙う方向に対して横向きになり、無理のない足幅で構えます。準備中に両足を離しておくプラットフォームスタンスなら、最初の練習を単純にできます。後ろ足を寄せる動き、ジャンプ、決められた膝の角度を、最初から加える必要はありません。力みを抑えつつ、ラケットを確実に保持します。

トスの通り道をそろえる

ラケットを持たない腕を滑らかに上げ、指からそっとボールを放します。余分な手首の跳ね上げを加えないようにしましょう。基本のサーブでは、無理なく上へ伸び、少し前方で触れるトスを探します。体を大きく反らせたり、よろけて追いかけたりする位置は避けます。

ちょうどよい高さは、腕の届く範囲とスイングのリズムによって変わります。ボールの回転数やラケットから何センチ上という一つの数値を追う必要はありません。予定した動きをする時間が取れることが大切です。明らかにずれたら無理に打たず、安全にボールを扱ってやり直します。

練習1：打たずにトスを確かめる

この練習の目標： 同じ無理のないスイングで届く位置へ、数球続けて上げること。

  1. 利き手にラケットを持ち、普段の開始位置に立ちます。
  2. 腕を上げて静かに放し、無理に手を伸ばして捕らず、片づいたコートへ落とします。
  3. 後ろ、遠い横、意図した位置より大きく前へ、繰り返し流れていないかを見ます。
  4. 手首を静かにする、腕の上げ方を滑らかにするなど、一つの意識で数回試します。開始位置は変えません。

落下位置はトスのばらつきを見る簡単な目安です。最適な打点を正確に測るものではありません。フルスイング時に踏みそうな場所へ、輪、タオル、かごなどを置かないでください。トスが扱いやすくなったらスイングへつなぎ、その場で上げるだけの練習を延々と続けないようにします。

練習2：準備を小さくした軽いサーブを加える

この練習の目標： 速さを求めず、トスと接触のタイミングを合わせること。

  1. ベースラインからでは難しければ、サービスラインに近い位置から始めます。対角方向の、周囲に余裕がある広い目標を選びます。
  2. 無理のない小さな準備から、軽い頭上のスイングを行います。コンチネンタルグリップを保ち、強く握り込みません。
  3. ボールへ上向きに伸び、ラケットを自然に振り抜きます。背中側へ深く落とすことや、手首を下へ強く折ることを無理に行わないでください。
  4. 短いまとまりで打って休み、また試します。楽に制御できる間だけ、少しずつ後ろへ下がります。

近い位置から始めるのは練習用の段階づけです。試合のサーブはベースラインの後ろから、フットフォールトの規則に従って行います。その位置へ戻ったときも、すぐ全力にせず、軽いリズムを保ちましょう。

違和感や痛みがある動きは止めます。技術は資格や経験のあるコーチに確認してもらえますが、続く痛みは適切な専門家に相談してください。

練習3：広い目標へ打ち、結果を記録する

この練習の目標： 一球ごとに狙いを持ち、次に使える情報を集めること。

  1. ベースラインの後ろから、正しい対角のサービスボックスの半分ほどを狙います。最初はラインから離れた範囲を選びます。
  2. 同じ準備と無理のない力加減で、たとえば5球を打ちます。
  3. 狙った範囲に入った数と、一番多いミスを記録します。打たずにやり直したトスも、別に記録しておきます。
  4. 反対側からも試します。同じ傾向が続くなら、次のまとまりでは一つだけ変えます。

数える目的は、自分の練習同士を比べることです。全員共通の合格点ではありません。制御できるようになったら目標を小さくしたり、試合に近いルーティンを使ったりできます。速さ、コース、回転を一度に変える必要はありません。

ミスを原因の手がかりにする

ネットミスが続く： 低いトスや前へずれたトスを追わなかったか、上へ伸びる動きが途中で止まらなかったかを見ます。ただし、ネットにかかっただけでトスが前すぎたとは断定できません。

長く外れる： 数球のトスと接触を比べます。面の向きやスイング方向も関係します。長いミスのたびにトスをコート奥へ動かすと、別の問題をつくることがあります。

早い段階でガット面が上を向く： 握りとスイングへ入る経路をコーチに確認してもらいます。肩をさらに後ろへ無理に動かすのではなく、楽にできる動作を保ちましょう。

練習では入るのにゲームで崩れる： 広い範囲へのサーブ1球から、相手と穏やかにポイントを続ける小さなゲームを試します。実際のポイント間でも使える、短い準備手順にします。

再現できるポイントを持ち帰る

最後に広い目標へ、軽くもう一まとまり打ちます。トスがどう動いたか、狙った範囲へどれくらい入ったか、何を意識するとよかったかを記録してください。見るのは数球に共通する傾向です。力を増やしたことが結果を改善したか判断できるようになってから、速さを課題にしましょう。

練習したサーブを、ポイントの中で確かめる

広い目標でつかんだリズムは、相手がレシーブするときも保てていますか。練習のポイントや試合を撮影し、SportArc Auto Cutでラリーのハイライトを作れます。ラリーの始まりを見返して、トスやリズム、サーブ後の準備を、このサーブ練習の観察点と比べましょう。

次の段階では、自分の状況と目標をもとにSportArcで個別のテニストレーニングプランを作成できます。気づいた問題をサーブ練習の重点にすれば、次の一かごにも、ただ数を打つ以上の目的ができます。

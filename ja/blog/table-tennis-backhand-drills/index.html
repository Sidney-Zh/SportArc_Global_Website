卓球執筆：Sijin2026年9月12日

卓球のバックハンドが続かないときに試したい3つの練習

体の前で打つ感覚をつかみ、コースと小さな移動を加えて、次の1球にも備えられるバック打ちを練習します。

2球までは返せるのに、次の球が体に近づくと肘が引けてネットにかかる。そこで強く振ると、かえってラリーが短くなることがあります。

卓球のバックハンドは、まず体の前の打ちやすい位置で捉え、打ったあとに戻れる小さな動きから練習しましょう。安定した球を送ってくれる相手か、無理なく打てる速さに設定したマシンがあれば始められます。

今回練習するのは基本のバック打ち

シェークハンドで、軽い上回転の決まった球を返すバック打ちを扱います。自分の打球にも少し上回転はかかりますが、強い下回転を持ち上げるバックドライブの大きな上向きの動きとは分けて考えてください。

相手が下回転ばかり送っているなら、ラケットの角度や振る方向を変える必要があります。最初は球質をそろえてもらいましょう。毎回違う球だと、自分の修正がよかったのか判断しにくくなります。

右利きを基準に説明しますが、左利きなら左右を逆にします。どちらでも、体の前に打つための空間を残すことが大切です。

構えは楽に、振りは小さく

台におおむね正対し、足を自然に開いて膝を軽く緩めます。台に覆いかぶさらず、肘を脇へ引き込まなくても届く距離を選びましょう。全員に合う固定の距離はありません。

ラケットはお腹の前、肘は体より少し前に置き、前腕が動く余裕をつくります。球が来る前から強く握ると、面の微調整が難しくなります。

安定した球なら、バウンドの頂点付近を打つ目安にしてみてください。前腕を前へ、少し上へ動かし、打ったらラケットを体の前へ戻します。大きく振り切るより、繰り返せる短い動きを目指します。

手首は落ち着かせますが、固める必要はありません。最初から手首を強く返す動きを加えず、当たりが安定してから速さや回転を練習しましょう。

練習1：同じ打点を見つける

ねらい：窮屈になったり手を伸ばしたりせず、数球続けて返す。

  1. 相手に同じ位置からバック側へゆっくり送ってもらいます。ラリーが難しければ1球ずつで構いません。
  2. 相手のバック側の広い範囲へ返します。お互いに構え直せる速さにします。
  3. 毎回ラケットを体の前へ戻し、次の球のバウンドを見ます。
  4. まず気持ちよく5球返すことを目安にします。打点が崩れたらやり直しましょう。5球は合格基準ではありません。

球が体に近すぎるなら、振りを変える前に立ち位置を調整します。手を伸ばしているなら球の通り道へ少し近づきます。相手にも、何球か続けて体の前で打てているか見てもらいましょう。

5球が楽になったら、同じ速さのままラリーを延ばします。すぐに速くすると、せっかくつかんだ感覚がわかりにくくなります。

練習2：広いコースを狙う

ねらい：小さな振りのまま方向をそろえる。

  1. 球出しは変えず、相手のバック側半面など大きな範囲を狙います。台の上にバウンドを邪魔する物は置きません。
  2. ゆっくり5球打ち、狙った範囲に何球入ったか確認します。
  3. ネットミスなのか、長く出たのかを分けて見ます。
  4. 次は面の角度か前へ送る強さなど、ひとつだけ少し変えます。

まだ台の端を狙う必要はありません。余裕のある目標のほうが変化を確認できます。少し浅くても楽に捉えられたなら、動きを全部やり直す必要はありません。

同じ範囲へよく入るようになってから目標を狭めます。最初から1球ごとにコースを変えず、別の方向は次の段階で加えましょう。

練習3：少し動いて、同じ打ち方で返す

ねらい：球の位置が少しずれても打つ空間を保つ。

  1. バック側の中で、近い2か所へ交互に送ってもらいます。
  2. 足で位置を調整し、体の前で打てるようにします。腕だけを横へ伸ばして追いません。
  3. いつもの小さなバック打ちで返し、ラケットを戻します。
  4. 短いラリーで練習します。慌てたり体の横で打ったりするなら、固定の球出しへ戻ります。

走り込む練習ではないので、間に合わなければ2点を近づけます。足を強く踏んだり、靴を鳴らしたりする必要はありません。

慣れたら、速さ・移動範囲・ランダム性のどれかひとつを増やします。同時に難しくしないほうが、何が変わったか確認しやすくなります。

ミスが続くときに見るところ

ネットにかかる：まず打ち遅れや窮屈な位置を確認します。同じ簡単な球に対して、面を少し開くか、上への動きを少し足してみます。

長く出る：前へ送る強さを落とし、面が開きすぎていないか見ます。無理に下へ押さえるより、小さな振りのほうが調整しやすくなります。

続けるほど振りが大きくなる：打ち終わりを確認し、ラケットを戻す時間が取れる球出しにしてもらいます。

試合になると使えない：最初の数球だけバックで続け、そのあと自由にする練習試合を試します。少しずつ実際のラリーにつなげましょう。

次の練習へ、ひとつだけ持ち帰る

最後に固定の球出しをもう一度行います。打点は見つけやすくなったか、次の球に間に合ったか、小さく動いても似た振りを保てたかを見ます。

「体の前に余裕を残す」「振り終わりを短く」など、役立った言葉をひとつ残しましょう。動画を見るなら、うまくいった1球だけでなく数球続けて比べると、次に練習することが見えてきます。

バック打ちが詰まる理由を、動きから探す

続けられるときと、体の前が窮屈になるとき。台に入ったかどうかだけでは違いが分からないこともあります。バック打ちを撮影し、SportArc AI Coachで動作の分析とフィードバックを確認すると、自分の動きを理解する手がかりが増えます。

体の前の余裕、小さなスイング、次球への準備など、このバック打ち練習と結びつく点を一つ選びましょう。一定の球で練習してから一歩の移動を加え、再び撮影して比較します。自分で繰り返せる動きを少しずつ固めていけます。

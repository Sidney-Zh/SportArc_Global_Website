テニスのリターン練習：まず返して、次の1球につなげる

テニスのリターン練習を3段階で紹介します。構え、コンパクトな準備、返球コースを整え、決まったサーブから次の1球へ進めましょう。

普通のラリーなら打てるフォアハンドが、サーブを受けると急に忙しくなる。ラケットの準備が終わる前にボールが来て、普段の大きなスイングが間に合わない。リターンではまず、無理なく打つための時間と距離を確保します。

このテニスのリターン練習は、基本的なラリーができ、サーブの速さを調整できるシングルスのプレーヤー向けです。やさしいサーブを繰り返せるパートナーと、決まったコース、二つのコース、次の1球の順に進めましょう。毎回リターンエースを狙うのではなく、目標を持って返し、バランスよくラリーに入ることが目的です。

動き出せる構えをつくる

主なサーブの方向をカバーでき、ボールとの距離を取りやすい位置に立ちます。膝を無理なく曲げ、ラケットを体の前で準備しましょう。待つときのグリップは、普段のフォアとバックの持ち替え方に合わせます。どんな打ち方にも合う、唯一の待ち方があるわけではありません。

サーバーの打つリズムに合わせて、小さなスプリットステップを行います。方向が見えたときに、安定した足元から動き出せることを狙います。高く跳ぶ、硬く着地する、サーブよりずっと前にステップを終えて止まる、といった動きでは、もう一度体勢を整える必要が生まれます。

立つ位置も実際のサーブに合わせます。速い球なら余裕が必要になり、遅い球なら少し前へ入れることもあります。位置を少し変え、同じサーブで試しましょう。他の人に合うからといって、ベースラインからの距離を固定する必要はありません。

時間がないときは準備を小さくする

リターンでは、ゆっくりしたラリーと同じ大きさのテイクバックが必要とは限りません。早めに体を向け、大きく回さずにラケットを準備します。腕を体に固く押し付けず、体と腕を連動させましょう。

バウンド後、体の前に余裕を残して打ち、狙った方向へ送ります。打った後は自然に振り抜きます。コンパクトなリターンにも準備とフォロースルーがあり、動かないラケットをただ差し出すだけではありません。

サーブは必ずバウンドしてから返します。高く弾む球が苦手なら、位置やバウンド後の打つタイミングを調整しましょう。ノーバウンドでサーブを打つと、そのポイントを失います。

練習1：サーブもリターンもコースを決める

練習の目的： コースを予想する負担を減らし、準備と打球をつなげること。

  1. サービスボックス内の決めた場所へ、やさしい速さでサーブを打ってもらいます。
  2. 構えから始め、相手の動作に合わせて小さくスプリットステップをします。
  3. バウンド後、コンパクトな動きでコート内の広い目標へ返します。
  4. リターンで止め、構え直して繰り返します。短い本数を打ったらサイドを替えます。

返す場所はサーブのコースに合わせます。ボディーやセンターへのサーブなら、まず相手コート中央の広い範囲を狙えます。ワイドへのサーブでは、無理にストレートへ変えるより、楽にクロスへ返すほうが余裕を取りやすい場合があります。どちらもラインぎりぎりを避けましょう。

短い本数の中で、最初に困る点を探します。体が詰まるなら距離を見直し、球が来てもラケットを後ろへ引いているなら準備を小さくします。動きを整理する間は、サーブを遅くしてもらうことも有効です。

練習2：速さを保ち、コースを二つにする

練習の目的： 覚えた順番ではなく、実際のサーブを見て動くこと。

  1. ワイドとボディー寄りなど、二つの場所を決め、サーバーに選んでもらいます。
  2. 速さは最初の練習と同じ程度にします。
  3. ボールを見て足を調整し、来球の方向に合った目標へ返します。
  4. 1球ごとに構え直し、ミスだけでなく判断も比べます。

テニスのリターン練習で、ここから急に全力サーブへ変えると、課題が重なりすぎます。まずはコースの不確実さだけを増やし、二人とも練習を進められるようになってから速くしましょう。

トスだけを見て、片側へ完全に動いてしまわないようにします。相手の傾向を読むことはできますが、打った後もボールを見続けます。早く当てずっぽうで動くのではなく、使える情報から動き出す練習です。

練習3：リターンの後に、もう1球打つ

練習の目的： リターンを、次の球が打てる位置につなげること。

  1. 扱いやすい速さのサーブと、広い目標で始めます。
  2. リターンを打ち、その方向に合わせてポジションを整えます。
  3. サーバーに次の球を無理のない速さで返してもらい、こちらももう1球打ちます。
  4. そこで止め、短い本数を決めて役割を交代します。

今度は、リターンがネットを越えたかだけでなく、次の球に備えられたかを見ます。ラインを狙いすぎて、自分の体勢を崩していないでしょうか。無理に一発で決めようとするより、広い範囲へ安定して返すほうが、ラリーを始めやすいことがあります。

実際に遅いサーブで時間があれば、目標を保ちながらスイングを大きくしても構いません。ただし、セカンドサーブが必ず簡単な球とは限りません。速さ、弾み方、使える時間を見て判断します。

繰り返せるリターンを確認する

最後は最初の決まったコースへ戻りましょう。テニスのリターン練習の前後で、準備とボールとの距離がどう変わったかを比べます。早めの準備や小さなテイクバックなど、役立った一つの手がかりを残し、次回もサーブを速くする前に確認してください。

ラリーを始めたリターンを見直す

リターン練習の後に、練習試合を1セット撮影してみましょう。SportArcのAuto Cutは、撮影したテニス動画をラリーやハイライトに整理できます。ラリーの始まりを自分で見返し、相手がサーブを打つときの準備、インパクトの余裕、時間がないときのコース選択を比べます。

リターンエースだけでなく、その後のラリーにつながった返球も参考にしてください。同じ問題が繰り返されるなら、速さを抑えたサーブとリターンの練習へ戻します。準備が遅れる場合と、ラインに近すぎる目標を選ぶ場合では、練習の重点が違います。

SportArcのアプリ内で、自分の状況と目標に合わせたテニスの個別トレーニングプランを作成できます。リターンの課題を一つ次回へ持ち込み、その後もう一度練習試合を撮って、予測しにくいサーブでも実行できるか確かめましょう。

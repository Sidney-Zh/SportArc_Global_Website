バドミントンのショートサーブ練習：バックハンドで低く安定させる

小さなスイング、広めの落下目標、返球への構えを使って、バックハンドショートサーブを一つずつ整えましょう。

サーブはネットを越えたものの、さらに浮き上がってしまう。ラケットを構え直す前に、相手が前へ出て攻めてきます。次はネットぎりぎりを狙いすぎて、シャトルがネットにかかることもあります。

この練習では、バックハンドショートサーブでラリーを低く安定して始めることを目指します。対象は、ショートサーブを覚えたいダブルスの一般プレーヤーです。相手を惑わせるフリックサーブは、いったん分けて考えます。コートと数個のシャトルを用意し、狙うサービスコートを決めましょう。返球を加える段階では、練習相手がいると役立ちます。

どんなサーブを目指すか決める

シャトルは対角のサービスコートへ入れます。ショートサーブではネットの近くを通り、相手のショートサービスラインを越えた前方の範囲へ落とすことを狙います。慣れるまでは、ラインの内側に余裕を持たせてください。

低い軌道は相手の攻撃の選択肢を減らせますが、必ず弱い返球になるわけではありません。打った後の準備も大切です。シャトルを眺めて止まらず、ラケットを上げて構え直すところまでをサーブの練習に含めましょう。

無理のない準備から始める

親指を使うバックハンドの握りで、強く握り込みすぎず、ラケットを体の前に置きます。ラケット側の足を前にする構えは一般的ですが、足の位置、肘の角度、胸との距離を一つの形へ無理に合わせる必要はありません。小さく前へ動かせる、安定した位置を探します。

シャトルは羽根を持ち、コルク部分をガットへ向けます。ラケットを少し引き、面をわずかに開いて前へ動かします。打つためにシャトルを放し、接触の瞬間まで指で保持しないでください。放すときにひねって回転を加えることもしません。

低いサーブを打ちたいときは、大きく上へ跳ね上げる動きを避けます。ネットを越す分の高さを出しながら、最後に急な一押しを加えなくても繰り返せる小さな動きにします。

サービスのルールを確認する

ここではBWFの標準のサービス規則を前提にします。インパクト時、シャトル全体がコート面から1.15メートル未満にある必要があります。ラケットは最初にコルク部分を打ち、前へ振り始めてからサービスが完了するまで動きを続けます。サービス中は両足それぞれの一部がコートに触れ、その接地部分が静止している必要があります。正しいサービスコート内に立ち、境界線を踏まないようにします。

高さの目安が必要ならメジャーで測り、上限より低い位置に余裕を設けます。シャトルの筒を積み重ねても、正確な高さの基準にはなりません。特定の種別で別のサービス規則が使われる場合もあるため、大会の適用規則を確認し、標準の高さ規則と混同しないでください。

練習1：同じ軽い接触を繰り返す

この練習の目標： シャトルの飛び出し方をそろえること。

  1. 片側のサービスコートから、対角のサービスコート内の広い範囲を狙います。
  2. 毎回、同じ無理のない握りとシャトルの位置をつくります。
  3. 小さな引きと滑らかな前への動きで、5球ほどサーブします。
  4. ネット、高すぎる、長すぎる、横へ外れる、のどのミスが多いか見ます。一つだけ変えて、もう一度試します。

5球は比較しやすい単位の例で、決められた練習量ではありません。飛び出しがそろわないときは、コルクの位置が毎回同じか、早く握り込みすぎていないかを確かめます。接触を練習する間は、狙う範囲を広く保ちましょう。

練習2：ネット上の高さと落下位置を合わせる

この練習の目標： 必要な距離を保ちながら、軌道を低くすること。

  1. 相手にコート脇の安全な位置から高さを見てもらいます。自分は落下位置を見ます。
  2. ショートサービスラインのぎりぎりを狙わず、同じサーブを繰り返します。
  3. 浮くなら、上向きの動きを少し減らすか、面の角度を少し変えます。届かないなら、接触を通して前への動きが続いているか確かめます。
  4. 別の変更を加える前に、次のまとまりで比較します。

ネットミスのたびに強く振らないようにしましょう。力を増やした結果、次の球が高く浮くだけかもしれません。逆に、とても低く飛んでも、ショートサービスラインの手前へ落ちれば目標を達成していません。

練習3：サーブから1球目の返球へつなぐ

この練習の目標： サーブ後、次の球を打てる状態になること。

  1. 相手は通常の位置で構え、決めた範囲へ穏やかに返します。
  2. 同じ準備でサーブし、ラケットを上げてバランスよく構え直します。
  3. 決めた返球を打ったら止め、次のサーブ前に立ち位置を整えます。
  4. 安定して準備が間に合うようになったら、相手が二つの穏やかな返球を選べる形へ進みます。

相手の役割はサーブとラリーをつなぐ手助けで、毎回得点を狙うことではありません。準備が間に合わない状態が続くなら、予測できる一つの返球へ戻します。ダブルスでは、最初の返球を誰がカバーするかもパートナーと確認してください。

崩れたときに見るポイント

浮く球が続く： 接触でラケットを急に持ち上げていないか、ためらった後に握り込んで突いていないかを見ます。前への動きを小さく、途切れさせずに行います。

ネットにかかる： 力を足す前に、面の角度とシャトルの向きを確かめます。安定を取り戻す間は、ネット上の余裕を少し増やします。

方向が変わる： 接触時の面の向きと、準備のばらつきから確認します。ガット面のどの隅で打つかだけで、方向を決める固定のルールに頼らないようにしましょう。

一人ではできても相手がいると崩れる： 練習3で相手を段階的に加えます。いつもの準備を保ち、お互いが構えてから、必要以上に遅らせずサーブします。

次のゲームに持ち込む工夫を一つ選ぶ

最後と最初のまとまりを比較します。規則に沿って狙った範囲へ入ったか、軌道はどうか、返球へ構えられたかを見てください。役立った変更を一つ選び、次回も試しましょう。速さやフリックの変化は、この低いサーブの土台ができてから加えます。

ショートサーブと、その次の一打を見る

一人では低く打てるバックハンドショートサーブも、レシーバーがいると準備が変わっていませんか。練習のポイントや試合を撮影し、SportArc Auto Cutでラリーのハイライトにまとめましょう。ラリーの始まりを見返し、サーブの準備と打った後の構えを比較できます。

次はサーブの安定か、その後の準備か。課題を決め、自分の状況と目標をもとにSportArcで個別のバドミントントレーニングプランを作成できます。今日気づいた一つのことを、次の練習につなげましょう。

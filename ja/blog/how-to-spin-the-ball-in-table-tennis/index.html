卓球のドライブで回転をかけるには？フォアハンドの当て方から練習しよう

卓球のドライブで回転をかける感覚を、3つの練習で確かめます。やさしい球を使い、ボールとの接触、弧線、短いラリーへと進めましょう。

ラケットを上に振ったのに、ボールは台の向こうへ飛んでいく。次は薄く当てようとして、ネットに落としてしまう。この間で見つけたいのが、ボールをこすりながら、相手コートまで運ぶための前向きの力も伝える感覚です。

今回のテーマは、卓球のドライブで回転をかける基本です。フォアハンドの基礎打ちができる人を対象に、やさしい球に対して無理なくフォアハンドドライブを打つ練習を行います。まず接触、次に弧線、最後にパートナーとの短い連続練習を確かめます。サービスの回転、横回転、強い下回転へのドライブは、別の課題として扱いましょう。

こする方向と、ボールを前へ運ぶ動きを合わせる

インパクトでラバーがどちらへ動いているかに注目します。主に前へ押す当て方と、ボールの表面を上方向にもこする当て方では、球の飛び方が変わります。この基本練習では、予定する打点より下にラケットを準備し、前上方へひと続きに振りましょう。

ただし、薄くこすることだけを狙って、ほとんど空振りになる当て方では安定しません。反対に、当て方を変えずに強く振っても、単に遠くへ飛ぶだけかもしれません。まずは余裕のある速さで、かすっただけの接触、厚く当たった接触、こすりながら運べた接触の違いを確かめます。

ラケットの面を、どの球にも同じ角度で固定する必要はありません。少し伏せた面から始め、来球に合わせて調整します。グリップは動きを妨げない程度に力を抜きつつ、ラケットがぐらつかないように持ちます。強く握り続けたり、最後だけ手首を急に動かしたりしなくても構いません。

体とボールの間に余裕をつくる

ボールが体に近すぎると、ラケットを動かす場所がなくなります。パートナーには同じフォア側へ安定して送ってもらい、体の斜め前で楽に打てるよう足を調整しましょう。小さな体の回転も使い、窮屈な手先だけで動かそうとしないことが大切です。

打ちやすい高さを選ぶことも助けになります。やさしい球なら、バウンドの頂点付近を出発点にできます。ただし、すべてのラリーで守る決まりではありません。すでに低く、体に近い球になったら、同じ振り方を無理に当てはめず、球出しからやり直します。

練習1：自分で落とした球をこすって送る

練習の目的： 相手のタイミングに合わせる前に、繰り返せる接触を見つけること。

  1. フォア側に立ち、小さく振れる空間を確保します。足元のボールは片付けておきます。
  2. ラケットを動かせる距離を空けて、自分のコートにボールをそっと落とします。
  3. バウンド後、小さなフォアの動きで前上方へ打ち、ネットの向こうの広い範囲を狙います。
  4. 落とし方をそろえ、力を増やさずに接触と飛び方を比べます。

これは打球感覚の練習で、ルールに沿ったサービスではありません。高く投げすぎるとタイミングが難しくなり、体のすぐそばに落とすと振る場所がなくなります。簡単に繰り返せる落とし方にしましょう。

大きな打球音だけで回転を判断しないでください。こする接触を保ちつつ、似た弧線と落下位置を繰り返せるかを見ます。通常の動画はスイングの確認に役立ちますが、球が速く見えるだけで正確な回転数が分かるわけではありません。

練習2：やさしい球出しでも同じ接触を続ける

練習の目的： 相手が送った球でも、見つけた当て方を保つこと。

  1. パートナーに、同じフォア側へやさしく安定した球を送ってもらいます。
  2. 最初は1球ずつ打ち、その都度構え直します。
  3. エンドラインとサイドラインから余裕を取った、大きな目標範囲へドライブを送ります。
  4. 球出しと接触に無理がなくなったら、短い連続練習に進みます。

卓球のドライブで回転をかける練習では、来球をそろえると比較がしやすくなります。1球目が高い上回転、次が短い下回転なら、結果が違っても、直前の修正が間違っていたとは限りません。

パートナーにも、ブロックした感触を聞いてみましょう。返しやすいのか、予想より速いのか、同じ受け方でも上へ出やすいのか。これは参考になる感想ですが、回転数の測定ではありません。自分の接触感覚や実際の落下位置と合わせて確認します。

練習3：弧線を変える調整は一つずつ

練習の目的： 小さな変更と、実際の飛び方を結びつけること。

  1. 球出し、目標、無理のない力加減をそろえます。
  2. 前の練習でうまくいった動きで、短い連続打球を行います。
  3. オーバーが続くなら、滑らかなスイングを保ちながら、面を少し伏せて試します。
  4. ネットが続くなら、まず距離と接触を確認します。そのうえで、上へ振る動きを少し増やすか、面の伏せ方を弱めてみます。

どちらも、すべてのミスを直す万能の方法ではありません。打点の遅れ、球出しのばらつき、ほとんど触れていない接触でも、似たミスが出ます。一度に一つだけ変え、同じ状況で結果が安定するかを見ましょう。

全体が慌ただしいまま、指先だけで大きな弧線を描こうとする必要はありません。無理のない一連の動きで球を送り、繰り返せるようになったら、急に強く振るより先に球出しへ少し変化を加えます。

次回に残すのは、役に立った一つの感覚

最後は簡単な球出しと広い目標に戻ります。卓球のドライブで回転をかける感覚は、「打点に余裕ができた」「上方向へ滑らかに振れた」「来球に面が合った」と具体的に整理すると、次回も試しやすくなります。一つの手がかりを残し、そこからラリーを組み立てましょう。

次の練習で確かめるポイントを一つ選ぶ

フォアハンドドライブが1球ごとに変わるなら、同じ球出しで短い連続動作を撮影してみましょう。SportArcのAI Coachで練習に合う卓球の動作、利き手、フォア・バックの区分を選び、動作へのフィードバックを確認します。準備やボールとの距離など、見直す部分を一つ選ぶと練習に戻しやすくなります。

その際も、パートナーの感想や実際の落下位置を合わせて見てください。動作の分析は、ボールの回転数や摩擦の大きさを測るものではありません。一つ修正したら、同じやさしい球出しで、接触と弧線を繰り返しやすくなったか確かめます。

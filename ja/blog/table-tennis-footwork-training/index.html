卓球のフットワーク練習：バックとフォアを無理なくつなぐ

2か所の打球位置で卓球のフットワーク練習を始めましょう。移動、戻り、切り替えをつなげ、次のボールも窮屈にならずに打つための3つの練習です。

バック同士なら続くのに、フォア側へ来た途端に打ちにくくなる。腕はボールへ伸びても、足が元の位置に残り、体の横で詰まってしまう。何とか返せても、バランスが戻らないまま次のボールを迎えることになります。

今回の卓球のフットワーク練習は、そのバックとフォアの切り替えに取り組みます。基本のフォア打ちとバック打ちを、落ち着いた速さで続けられる人向けです。最初は2か所へ決まった順序で送ってもらい、移動する時間を確保しましょう。練習相手、台、数個のボールがあれば始められます。先に次の1球を楽に打てる位置を探し、速さは後から加えます。

それぞれの打ち方に必要な間隔をつくる

フォアとバックでは、体とボールの間に必要な空間がまったく同じとは限りません。ボールが左右に動いたら、足元の位置も調整し、ラケットを自然に出せるようにします。上体だけを大きく傾ければ1球は返せても、反対側への切り替えが難しくなります。

軽く膝を曲げてバランスを取り、ラケットを体の前に構えます。横への動きは、すぐに逆方向へ動ける大きさに。短い距離を右へ動くなら、左側で床を押し、右足をボールの方向へ出して左足を続けます。左へ動くときは逆です。小さな2点練習に、大きく足を交差させるステップを無理に入れる必要はありません。

これはすべてのボールで固定する姿勢ではなく、始めるときの目安です。台との距離も調整幅も、送られるボールによって変わります。毎回腕を伸ばし切ったり、大きく踏み込んだりしないと続かないなら、左右の幅を狭めてもらいましょう。

打ち終わりから次の1球を準備する

振り終わりが大きすぎると、ラケットが体の片側に残っている間に、次のボールが反対側へ来ます。無理のない速さでコンパクトに打ち、足を調整しながらラケットも次に使える位置へ戻します。打つたびに一度止まり、そこから準備をやり直す形にはしないでください。

相手が打つところを見て、来るボールを追いましょう。最初の練習では次のコースが分かっていますが、見る習慣は残します。順序が変わる段階では、覚えた動きを繰り返すだけでは対応できません。

練習1：ボールなしで2つの位置をつなぐ

ねらい： フォアとバックを楽に振れる距離を見つけ、その間の移動をつなげます。

  1. 台の後ろで構え、周囲に安全に動ける空間があることを確認します。
  2. バックの位置へ小さく調整し、コンパクトに素振りします。
  3. フォアの位置へ移り、必要な分だけ体を回して素振りします。
  4. 滑らかに戻り、バランスを保てる速さで繰り返します。

数回ゆっくり往復するだけでも、足が余計に交差していないか、腕が体の後ろに残っていないかに気づけます。左右へ大きく跳ぶ動きになったら、一度止めてやり直しましょう。これは動き方の準備であり、長時間の体力練習にする必要はありません。

どちらの方向も無理なく移れる幅にします。片側だけぎこちないなら、速くする前に距離を縮めます。実際のラリーで減らしたい「腕だけで届かせる動き」を、素振りで何度も繰り返さないようにしましょう。

練習2：バック1本、フォア1本

ねらい： ボールが入っても、打ちやすい間隔を保ちます。

  1. 相手にバック、フォアの順で交互に送ってもらいます。
  2. 相手が送り続けやすいよう、相談して決めた広めの範囲へ返します。
  3. 軽い基本打ちでつなぎ、腕を伸ばして合わせるのではなく、打球の間に足を調整します。
  4. 短い連続練習の後で止まり、最初に慌ただしくなった切り替えを振り返ります。

卓球のフットワーク練習では、次の打球を慌てずに準備できる連続動作を目指します。左右それぞれ数回、楽に切り替えるなど、小さな目標を決めてもよいでしょう。回数は練習を区切るための目安で、達成しなければ意味がないという基準ではありません。

フォアでいつも体が詰まるなら、その前のバックを打ち終えた位置を確認します。必要なのは強く床を蹴ることより、早めの戻りや小さなバックの振り終わりかもしれません。2人とも急いでいるなら、ボールの速さを落としましょう。

練習3：送る順序を決めない

ねらい： 実際に来たコースに合わせて、小さく動きます。

  1. 2か所の範囲と、余裕のある速さはそのままにします。
  2. 相手にフォアかバックを自由に選んでもらいます。
  3. 来球を見て必要な分だけ動き、決めた範囲へ返します。
  4. 見るより先に予想で動くようになったら、いったん交互の練習へ戻します。

同じ側へ2球続けば、わずかな位置調整で済むこともあります。前の1球で横へ動いたからといって、毎回同じ幅を動く必要はありません。この段階では、覚えた動作を速くするのではなく、足を実際のボールに合わせます。

困った場面に合わせて1つだけ直す

いつも腕で届かせているなら、送球の幅を狭め、ボールとの距離を確認します。打った後にバランスを崩すなら、振り幅や横への跳び方を小さくします。打つたびに足が止まるなら、ゆっくりした素振りの切り替えから、簡単なボールへ戻しましょう。

一度に変えるのは1つだけ。「振り終わりを小さくしたら移動が間に合った」という発見のほうが、握り、構え、ラケット角度、速さを同時に直そうとするより次に生かしやすくなります。

次回にも使える調整を残す

最後は最初のバックとフォアの交互練習に戻ります。打球時の空間は増えたか、次の1球への準備は早くなったかを比べましょう。役立った調整を1つ残して、今回の卓球のフットワーク練習を終えます。範囲を広げたり速くしたりするのは、基本の切り替えが安定してからで十分です。

切り替えの前に、1つの打法を見直す

交互の練習がいつも同じ側で途切れるなら、その基本打ちを一度切り離してみましょう。SportArc AI Coachが対応するフォア打ちやバック打ちを撮影し、フォームのフィードバックを確認します。役立つ合図を1つ選び、ゆっくりした2点練習へ戻してみてください。

練習全体の動画も残し、打点の空間や次への準備は自分の目で比べます。1つの打法へのフィードバックが、フットワーク全体を自動評価するわけではありません。映像で確認できる変化を選び、同じ落ち着いた球出しで試しましょう。

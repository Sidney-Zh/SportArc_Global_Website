バックハンドツッツキの練習：低い返球を身につける3つのドリル

一定の下回転に対してバックハンドツッツキを練習し、高さ、コース、打球後の戻りを一つずつ確かめましょう。

短いボールを返せても、高く浮いて相手に打たれてしまう。次はラケットをかぶせすぎてネットにかかる。この2球の間にあれもこれも変えてしまうと、何が原因だったのか分かりにくくなります。

バックハンドツッツキの練習は、同じ球を受け、小さく振り、一つの点を観察するところから始めます。対象は、シェークハンドで下回転を安定して返したい初級者です。緩やかで一定の下回転を送れる相手か、適切に設定した卓球マシンを用意してください。

ツッツキと攻撃的なバックハンドを区別する

ツッツキはボールの下側をこすり、下回転のボールを高さを抑えて返す技術です。弱い上回転の球を前上方へ打つバックハンドとは、取り組む課題が違います。最初は回転が分かっている球を使いましょう。上回転と下回転が不規則に混ざると、ミスを判断しにくくなります。

来球の回転に合わせてラケットの面を上向きに開き、体の前で触れる余裕をつくります。小さく前へ動かしてこすり、打ったら構え直します。大きくすくい上げたり、急に突いたりしないようにしましょう。ボールをラバーに乗せ続けようとせず、短い接触で自然に送り出します。

小さな動きで届く位置へ入る

膝にゆとりを持たせ、握りを固めすぎず、バランスよく構えます。短い球には近づき、肘を伸ばし切らずに届く位置を探してください。どの足をどこへ出すかは、ボールの落下位置で変わります。すべてのツッツキに共通する一つの足の位置があるわけではありません。

バックスイングは小さくします。短く返したいときは、バウンド後の早いタイミングで触れると長さを調整しやすくなります。毎回、来球の頂点より高くラケットを持ち上げる必要はありません。大きく振り下ろさなくてもボールの下に入れる準備位置を見つけましょう。

練習1：同じ下回転を安定して返す

この練習の目標： 回転が一定の球に対して、扱いやすい面の角度を探すこと。

  1. 相手に、同じバック側へ1球ずつ送ってもらいます。回転と長さも、できるだけそろえます。
  2. 相手コートの広い範囲を狙います。最初からネットすれすれを狙わず、返球できる高さの余裕を持ちましょう。
  3. 次の球の前に足とラケットを戻します。まず5球ほど試し、高く浮く、長く出る、ネットにかかる、のどれが多いかを見ます。
  4. 一つだけ調整して繰り返します。たとえば同じ球でネットミスが続くなら、面を少し開いて比較します。

5球は比べやすいまとまりの例で、必須の回数ではありません。送球が大きく変わった場合は、すぐに自分のフォームの問題とせず、条件をそろえてもう一度試してください。

練習2：台に収めながら高さを抑える

この練習の目標： ネットを越す余裕を残しつつ、浮く返球を減らすこと。

  1. 送球を変えず、広めの落下範囲を決めます。
  2. 相手にはネット上の高さを見てもらいます。自分は体の前で触れることに集中します。
  3. 浮く球が続くなら、上へ持ち上げる動きを減らすか、面の開きを少し小さくします。同時には変えません。
  4. 短いまとまりで再び比較します。台に安定して収まる場合に、その調整を残します。

低い球と短い球は同じではありません。短さを確かめるときは、相手が触らずにバウンドさせ、相手コート内で2バウンド目が入るかを見ます。ただし、すべてを無理に短くする必要はありません。低く、コースを意図した長いツッツキも有効です。

練習3：コースを決め、次の球へ戻る

この練習の目標： 返す場所を選び、打球後に次の球へ備えること。

  1. 同じ送球で、相手のバック側半分か、中央の広い範囲を狙います。
  2. 同じ小さな動きで、その範囲へ数球返します。
  3. 台の近くへ踏み込んだ場合は打球後に戻り、ラケットを構え直します。
  4. 次のまとまりで狙う場所を変えます。慣れたら相手にもう1球だけ穏やかに返してもらい、間に合うか確かめます。

コースと送球条件は別々に変えてください。その先では、相手に強めと弱めの下回転を事前に知らせて出してもらえます。それぞれの面の感覚をつかんでから、予告のない変化へ進みましょう。

ミスを見てから調整する

ネットミスが続く： 下回転が強くなっていないか、体に近すぎる位置や遅いタイミングで触っていないかを確かめます。同じ送球なら、面を少し開く調整が役立つことがあります。小さな調整を、大きなすくい上げに変えないようにしましょう。

高く浮く、長く出る： 来球の回転、面の向き、上へ持ち上げる量を比べます。回転が弱い球には、強い下回転と同じ角度が合わないことがあります。相手のラケット角度をそのまままねるのではなく、接触や飛び方も見てください。

左右へ外れる： 最初の練習では横回転を混ぜません。右利きのサーブだから必ずボールの右側に触る、という共通の処理方法はありません。実際の回転方向によって対応が変わります。

次回に残すポイントを一つ選ぶ

最後に、最初と同じ一定の送球へ戻ります。一番うまくいった1球ではなく、数球の高さと落下位置を比べましょう。「短い球に近づく」「振り終わりを小さくする」など、役立ったポイントを一つ残せば、次の練習を始めやすくなります。

ツッツキの返球だけでなく、自分の動きも見る

バックハンドツッツキの高さや長さを見ながら、自分の動作まで確認するのは難しいものです。ツッツキを撮影し、SportArc AI Coachのフィードバックを使って動きを見直してみましょう。返球の結果と合わせて、定着させたい点や調整したい点を考えられます。

一つの課題を選び、同じ下回転の球で試します。小さな動作を繰り返せるようになったら、コースと次球への準備を加えましょう。もう一度撮影して比較すれば、浮いた一球のたびに動作全体を変えずに練習を続けられます。

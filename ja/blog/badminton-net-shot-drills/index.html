バドミントンのヘアピン練習：浮かせすぎず、ネットを越すタッチへ

バドミントンのヘアピンを、その場のタッチから一歩の踏み込み、連続した返球へ。短いラケット操作と移動をつなぐ3つの練習を紹介します。

ネット前でシャトルに追いついたのに、返球が浮いて相手に攻められる。次は力を抜きすぎて、ネットを越えない。その差がわずかに感じられ、前へ急ぎながらラケット面まで調整しようとすると、さらに難しくなります。

今回のバドミントンのヘアピン練習では、まずタッチと移動を分け、後からつなげます。前方の届きやすいシャトルを、相手のネット前へ返す練習です。最初はまっすぐなヘアピンから。スピンやフェイント、ネット前でのプッシュは、繰り返せるタッチができてから取り組みましょう。

今回練習するショットを確認する

ヘアピンはネット近くで打ち、相手側でもネット近くへ落とすショットです。後方から頭上で打つドロップとは異なります。今回はシャトルがネットの白帯より下にあるため、まず越えられるだけ上向きに飛ばす必要があります。その位置から下へ打っても、ネットすれすれの返球にはなりません。

最初は白帯の上に目で分かる余裕を取ります。1本だけ見事にネットをかすめても、その後何度も引っかかるなら、安定した練習にはなりません。まずは越えて前方に落ちる弾道を繰り返し、タッチが落ち着いてから高さを細かく調整します。

短く、はっきりしたタッチにする

ラケットを体の前に用意しておけば、大きく後ろへ引かずにシャトルへ出せます。フォア側では無理のないフォアハンドの握り、バック側では親指を使いやすい握りへ調整します。面を保てる程度には支えつつ、最初から最後まで強く握り続けないようにしましょう。

突くのではなく、短く穏やかに当てる感覚です。ラケット面と小さな前方への動きで、シャトルを向こう側へ送ります。ガットに受け止めて運ぶのではありません。「柔らかく持つ」と考えてラケットがぐらつくなら、手を静かに保ち、動きを短くしてみてください。

練習1：その場で弾道を確かめる

ねらい： 浮きすぎずにネットを越えるタッチを見つけます。

  1. 自分のコート側で、簡単な球出しに無理なく届く距離に立ちます。
  2. 相手にはラケットの通り道を避けて、同じフォア側の位置へ1球ずつ投げてもらいます。
  3. 短い動きでストレートに返し、高さと落ちる場所を見ます。
  4. 少し続けてからバック側へ移り、握りを調整します。

まだ1球ごとに左右を変えません。同じ位置を繰り返すと、タッチそのものが安定しているか分かりやすくなります。球出しもできるだけ同じ高さに。高い球と低い球が大きく混ざると、別の課題になってしまいます。

高く浮くなら、前へ押す力を少し減らし、面が上を向きすぎていないか確かめます。ネットにかかるなら、次をさらに弱くするだけでは不十分です。越えるための上向きの方向があるかを先に見ましょう。

練習2：無理のない一歩を加える

ねらい： 体が前に動いても、同じタッチを残します。

  1. 最初の練習より少しだけ後ろから始めます。
  2. ラケットを来るシャトルへ出しながら、ラケット側の足でコントロールできる踏み込みをします。
  3. 体がすでに前へ進んでいる分を考え、手の動きは短く保ちます。
  4. 踏み込んだ姿勢から戻り、次の球出しまでにラケットを構え直します。

大きく伸びなければ届かない距離にはしないでください。これは手と移動を合わせる練習で、最大の歩幅を試すものではありません。膝と足先の向きを自然にそろえ、落ち着いて戻れる速さで行います。

手では同じように打ったつもりでも、体が前へ動いた分だけシャトルが遠くへ飛ぶことがあります。バドミントンのヘアピンでは、すぐに握りを変えるより、余分な手の動きを減らしてみましょう。動きを足すと毎回タッチがばらつくなら、その場の球出しへ戻ります。

練習3：協力してネット前のラリーを続ける

ねらい： 戻りと、次のシャトルに合う握りの準備をつなげます。

  1. まず片側でストレートのヘアピンを続け、白帯の上に余裕を取ります。
  2. お互いが準備できるよう、続けやすい球を返します。
  3. 安定したら、相手に届きやすい前方の2か所へ送ってもらいます。
  4. 来球に合わせてフォアかバックを準備し、返したら次に備えます。

球出しが低すぎたり遠すぎたりしたら、そこでやり直す約束にします。難しい位置からも毎回ヘアピンを強行すると、伸びて触るだけの練習になりがちです。試合なら別のショットが適することもあります。ここでは扱いやすい球でタッチを育てます。

短いラリーでも、最初の練習と比べられます。動き始めの1球だけが浮くのか、何球か続くとタッチが崩れるのか。前者なら前へ入る動作を小さくすること、後者なら打球間の戻りを丁寧にすることが、次に確かめる候補になります。

ミスから次の調整を選ぶ

高く浮く原因には、押しすぎ、面の開きすぎ、慌ただしい到着などがあります。ネットにかかる場合は、上向きの弾道が足りない、遅れて触って余裕がないといった可能性もあります。結果だけで原因を1つに決めず、簡単な球出しへ戻って1つずつ変えてください。

最後は苦手な側をもう一度練習します。「ラケットを早めに出す」「踏み込むときの手の動きを小さくする」など、次回のための合図を1つ残しましょう。バドミントンのヘアピンで繰り返せるタッチができれば、球の変化が増えたときにも確かめる基準になります。

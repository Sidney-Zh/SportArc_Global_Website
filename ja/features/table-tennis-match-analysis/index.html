卓球 · 試合レビュー

試合動画から、卓球のプレーを振り返る。

固定したスマホで試合全体を撮影し、SportArcに読み込みます。試合レビューでは、ボールの着地点や打球の統計、文章のレポートを動画と合わせて確認できます。

着地点や打球データを、試合動画と合わせて確認

試合レビュー（Match Review）では、録画した卓球の試合から、着地点や打球の統計、文章のレポートを確認できます。どの場面のデータなのかを、元のプレーと一緒に見返してください。

着地点の分布を見る

ボールの着地点がどこに集まっているかを、マップで確認できます。動画で実際のプレーも見ながら、試合中のコースを振り返れます。

打球の傾向とレポートを読む

打球の統計や速度など、表示されるデータから試合を見返せます。文章のレポートと動画を合わせて、次に確認したい場面を整理してください。

固定したスマホで、試合を撮る

試合レビュー用のアングルから、スマートフォンを動かさずに撮影してください。卓球台、ボール、両側の選手が見えることが必要です。複数のカメラ位置が切り替わる映像では、この撮影条件を満たしません。

動画と試合の情報を用意する

  1. 試合の動画を読み込む

    卓球の試合レビューを開き、「写真」または「ファイル」から、カメラを同じ位置に固定して撮影した動画を選びます。アップロード後はアプリの案内に沿って進めてください。

  2. 試合中の位置を指定する

    アプリの案内に従い、チェンジエンドと開始時の自分の位置を指定します。

  3. 結果を動画と見比べる

    着地点や打球データ、レポートを確認します。気になる傾向は、そのときのプレーも見ながら振り返ってください。

よくある質問

始める前に確認しておきたいこと。

手入力した試合の勝率を集計する機能ですか？

ここで紹介する試合レビューは、卓球の試合動画をもとにデータとレポートを確認する機能です。試合結果だけを入力する記録アプリとは、用意する情報が異なります。

自動編集との違いは何ですか？

自動編集は、検出されたプレー区間を選んで動画として書き出すための機能です。試合レビューでは、撮影条件に合った卓球の試合から着地点や打球データなどを確認できます。

AIコーチとの違いは何ですか？

試合レビューは1つの試合を振り返ります。AIコーチは、対応する1つの技術動作を3Dやフィードバックで確認します。

撮影中にスマホを動かしてもよいですか？

試合レビューでは固定したカメラ位置が必要です。途中で動かしたり、別のアングルへ切り替えたりせず、撮影ガイドの条件を守ってください。

どの端末で使えますか？

SportArcはiPhoneとiPadで利用できます。アプリは無料でダウンロードでき、アプリ内購入があります。機能ごとの利用条件とPlusの内容は、アプリ内でご確認ください。

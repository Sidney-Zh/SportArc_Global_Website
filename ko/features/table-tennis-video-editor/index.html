탁구 · 자동 편집

긴 탁구 영상에서 다시 볼 랠리를 골라 보세요.

공을 줍거나 다음 포인트를 준비하는 시간까지 담긴 경기 영상. SportArc 자동 편집으로 플레이 구간을 찾고, 연습에 참고하거나 함께 보고 싶은 랠리를 남길 수 있습니다.

처음부터 끝까지 돌려보지 않고, 플레이부터 확인하세요

촬영한 탁구 영상을 가져오면 자동 편집이 플레이 구간을 감지합니다. 감지된 클립을 재생해 보고, 다시 확인할 랠리나 공유할 장면을 직접 고르세요. 경기 결과를 기록하는 일과, 실제 플레이를 영상으로 남기는 일은 다릅니다.

  • 클립을 먼저 확인하세요. 자동 감지된 플레이를 재생하며 필요한 장면을 찾습니다.
  • 남길 장면은 직접 고르세요. 내보낼 클립을 선택해 저장하고 함께 볼 수 있습니다.

감지된 구간을 한눈에

자동 편집 화면에서 영상의 플레이 클립을 살펴볼 수 있습니다. 이 화면은 테니스 예시이며, 종목마다 제공되는 편집 기능은 다릅니다.

영상을 가져오고, 랠리를 골라 내보내세요

  1. 종목과 경기 형식 선택

    탁구 자동 편집을 열고 영상에 맞는 단식 또는 복식을 선택하세요.

  2. 촬영한 영상 가져오기

    사진 또는 파일에서 경기·연습 영상을 선택하고 처리를 시작하세요.

  3. 플레이 구간 확인

    감지된 클립을 재생하며 다시 볼 장면을 확인하세요.

  4. 선택한 클립 내보내기

    남기거나 공유할 구간을 선택해 영상으로 저장하세요.

탁구대 양쪽과 공, 선수의 움직임을 담으세요

아래 촬영 예시를 참고해 탁구대 양쪽과 선수, 공이 화면에 들어오는 위치를 고르세요. 앞에 선 사람이나 옆 테이블에 플레이가 가려지지 않는지 짧게 시험 촬영해 보세요. 경기 리뷰도 이용하려면 해당 기능의 고정 촬영 구도를 따로 확인해야 합니다.

자주 묻는 질문

시작하기 전에 확인하세요.

자동 편집에서도 경기 데이터를 볼 수 있나요?

자동 편집은 플레이 구간을 확인하고 선택해 영상으로 내보내는 기능입니다. 낙하지점이나 타구 통계, 분석 보고서를 보고 싶다면 탁구 경기 리뷰에 맞는 구도로 촬영하세요.

원하는 랠리만 저장할 수 있나요?

네. 자동으로 감지된 클립을 재생해 보고, 내보낼 구간을 선택할 수 있습니다. 저장하기 전에 필요한 장면이 포함됐는지 확인하세요.

스윙 자세를 자세히 보고 싶다면요?

한 번의 기술 동작을 살펴보려면 탁구 AI 코치를 선택하세요. 지원되는 동작과 임팩트 프레임, 분석할 선수를 지정해 3D와 피드백을 확인합니다.

복식 영상은 어떻게 준비하나요?

자동 편집에서 영상에 맞게 복식을 선택하세요. 촬영할 때는 네 선수가 움직여도 화면에 들어오고 공이 보이는지 확인하세요.

어떤 기기에서 사용할 수 있나요?

SportArc는 iPhone과 iPad에서 사용할 수 있습니다. 무료로 다운로드할 수 있으며 앱 내 구입이 있습니다. 기능별 이용 조건과 Plus 혜택은 앱에서 확인하세요.

網球接發球練習：接穩來球，銜接下一拍

三個網球接發球練習，從預備姿勢、精簡引拍到回球目標。先練固定落點，再增加方向選擇，最後接進下一拍。

平常底線對打還算從容，對方一發球，正拍卻突然來不及了。球已經到身邊，球拍還沒準備好；原本順手的大幅揮拍，也很難及時完成。接發球首先要找回的，是舒服的擊球距離，以及足夠的準備時間。

這組網球接發球練習適合已能對打、也能控制發球速度的單打球友。與能重複發出簡單來球的搭檔練習，先固定一個落點，再加入方向選擇，最後多打一拍。目標是帶著平衡和明確方向進入回合，不必每球都接發直接得分。

讓預備姿勢幫你啟動

站在能照顧主要發球方向、又方便留出擊球距離的位置。膝蓋自然彎曲，球拍準備在身前。等待時的握拍配合自己平常正反拍的轉換習慣，讓兩側都能調整；不是所有正反拍組合都適合同一種等待握法。

配合對方擊球節奏，做一個小幅分腿墊步。重點是看出方向後，能從穩定的支撐狀態移動。不必跳很高，也不要僵硬落地。若對方還沒打球，你就早早墊完、重新站死，反而多了一次啟動。

站位也要看實際來球。較快的發球可能需要多留空間，較慢的球可能允許你靠前。每次稍微調整，再接同樣的發球比較，不要因為別人站在底線後某個距離，就照搬到自己身上。

時間不夠時，先精簡引拍

接發球不一定能使用慢速對拉時的完整引拍。及時轉身，把球拍帶到適合的位置，減少不必要的大幅繞拍。手臂與身體協調，不是把雙臂僵硬地夾在身上。

等球落地彈起，在身前留出空間，將球送向目標，再自然隨揮。精簡的動作仍有準備、觸球和隨揮，不是把不動的球拍伸出去碰運氣。

發球必須落地後才能回擊，不能直接截擊。若發球彈得太高，調整站位或落地後的擊球時機；在尚未落地前擊球，會失掉這一分。

練習一：固定發球方向，固定回球目標

練習目的： 先減少猜測落點的負擔，連起準備與擊球。

  1. 請搭檔以容易處理的速度，發向發球區內一個約定位置。
  2. 從預備姿勢開始，配合對方動作完成小幅分腿墊步。
  3. 等球落地，以精簡動作回向場內較大的目標區。
  4. 接完就停下、重新準備，練一小組後再換邊。

目標要配合發球。面對追身或中線附近的發球，先回對面中路的大範圍；面對外角發球，舒服地回斜線，通常比勉強改直線更有餘裕。都要與邊線留出距離。

短短一組，先看最早卡住的是什麼。球總擠到身體，就檢查間距；球到了、球拍還往後走，就簡化引拍。把發球暫時放慢，可以幫助你把動作整理清楚。

練習二：維持速度，改練兩個落點

練習目的： 根據真正的來球選擇移動，不是背固定順序。

  1. 約定兩個位置，例如偏外角和靠近身體，由發球方自行選擇。
  2. 速度維持與第一個練習相近。
  3. 看球、調整腳步，選擇適合來球方向的回球區。
  4. 每球後重新準備，除了失誤，也比較自己的判斷。

這一步先增加落點的不確定性，不要同時改成全力發球。否則網球接發球練習容易變成雙方都無法控制的搶球。等兩人都能順暢完成，再增加速度。

不要只看拋球就完全撲向一側。可以注意對方習慣，但擊球後仍繼續追蹤球。這是練習用看得到的資訊啟動，不是越早猜方向越好。

練習三：接發之後，再打一拍

練習目的： 把回球與能繼續對打的位置接起來。

  1. 使用可控的發球速度與較大目標區。
  2. 回擊發球，依自己的回球方向調整位置。
  3. 請發球方再打一拍可控的球，你也再回一拍。
  4. 到這裡結束，完成約定的小組後交換角色。

現在不只看接發有沒有過網，也看是否站得穩、來得及準備下一球。為了追邊線而失去位置，不一定比穩穩送進大範圍更有效。能接進下一拍，才真正開始這一分。

若實際來球較慢、時間更多，可以保留目標並採用較完整的揮拍。但「二發」不必然等於好打的球，仍要根據速度、彈跳和自己有多少時間判斷。

留下一個能重複的提示

結束網球接發球練習時，回到最初已知的落點，比較準備和擊球距離是否更從容。留下例如提早準備、縮小引拍等一個有效提示，下次先重複做到，再提高發球速度。

桌球短發球：用第二跳練好長度與高度

練習桌球短發球，先看球在對方桌面的第二跳能否留在桌內，再控制過網高度，逐步加入落點與接發球練習。

球第一次落在對方網前，看起來已經很短，接著卻一路向前，從球桌端線掉了下去。下一次發球，你把力量收得更小，球又掛在網上。一直在這兩種失誤之間來回，很容易不知道該先改哪裡。

這組桌球短發球練習，把長度和高度分開觀察。先選一種熟悉的發球，不安排接球，讓球完整彈跳；看清第二跳後，再加入目標區和接發球同伴。準備一張球桌和幾個球，每次都留一點時間看完球的運行。

從第一球開始保留合法發球流程

將球放在靜止、張開的非持拍手掌上，近乎垂直向上拋起，不主動給球加旋轉。球離開手掌後至少上升16公分，在下降過程中擊球。觸球前，球應一直位於桌面之上、端線之後，並讓接球方看得見；拋球後及時把非持拍臂移出球與球網之間的空間。

球必須先在己方桌面彈跳，再落到對方桌面。雙打時，這兩次落點都要位於相應的右半區。獨自練習也保持這個流程，不用降低拋球或遮擋觸球的方式解決短發球難題。

每次發球前先站穩、準備好，不必急著把一盆球發完。起始流程相近，前後結果才容易比較，也更方便把練習帶進比賽。

看對方桌面的第二跳

檢查短發球長度時，可以先不接球，觀察它是否會在對方桌面上再彈第二次，之後才離開球桌。這裡的「第二跳」只數對方半桌：完整過程是己方一跳、對方兩跳，也就是整次發球的第三次桌面接觸。

第一落點靠近網，並不能證明球足夠短，要繼續看後面的運行。同樣，球雖然短，也可能過網太高，讓對手有機會進攻。所以長度和過網高度要分開記錄。

己方第一跳的位置可以作為調整線索，但它不能獨自決定結果。觸球高度、方向、速度和旋轉也會改變球路。練習開始時，先固定一種熟悉的發球和一個方向。

練習一：讓球完整彈跳

練習目的：不依賴接球方的反應，自己辨認發球長度。

  1. 不安排接球，發球後讓球繼續彈跳。
  2. 觀察對方桌面的第二跳是否仍留在桌上。
  3. 另外記錄球是低平過網，還是明顯冒高。
  4. 先發一小組，例如五個球，再選擇一個地方調整。

五個球只是便於暫停和比較的示例，不是必須完成的訓練量。可以一組結束後再撿球，讓注意力留在同一種發球上，不急著換動作。

如果球總是出桌，稍微減少向前送球的力量，同時保持乾淨觸球。如果接下來開始下網，先檢查球路和觸球的穩定度，不要馬上恢復成更用力的一拍。目標是找到能重複的合適範圍。

練習二：加入明確的落點區域

練習目的：在發短的同時，讓方向有計畫。

  1. 利用球桌現有線條作參照，在對方半桌選一個較大的目標區。
  2. 保持原來的發球，不同時增加新的旋轉變化。
  3. 發向目標後繼續觀察，既看第一落點，也看下一跳。
  4. 第一落點進入目標區、隨後仍滿足短球長度檢查，才算完成這次任務。

目標區先留寬一些，方便看出規律。過早瞄準極小的點，可能讓每球都像失敗，反而忽略長度已經逐漸穩定。

練桌球短發球時，同時改變落點、速度和旋轉，很難知道哪項調整起了作用。先把這一個任務練清楚，能說出最常見的失誤，再調整與它最相關的一處細節。

練習三：讓同伴開始接發球

練習目的：有人準備接球時，仍能保留熟悉的發球。

  1. 請同伴正常接發球，你繼續保持同樣的短球意圖。
  2. 沿用上一組練習的準備動作和目標區。
  3. 看發球飛行與回球結果，再準備下一次發球。
  4. 幾次有人接球的練習後，穿插幾次不接球的長度檢查。

球一旦被接回，就看不到原本的第二跳，因此不能完全用回球結果代替長度檢查。同伴可能把一顆不錯的發球接好，也可能對一顆偏鬆的球失誤。把回球當作補充資訊，不用每一次丟分來判定發球失敗。

如果有人接球後你開始趕動作，先回到第一組的穩定準備。讓熟悉的發球保留下來，再逐漸增加壓力。

讓修正對應實際失誤

短，但冒高：在保留足夠向前運行的同時調整過網高度。簡單地把力量全部收掉，可能讓球還沒過網就落下。

低，但出桌：保持觸球和方向，重點調整長度。用第二跳檢查稍小的向前力量是否有幫助。

頻繁下網：先檢查過網餘量和觸球的穩定度，再考慮增加旋轉。基本球路還不穩定時，動作越複雜越難判斷。

每球結果都不同：回到一種發球、一個目標和不趕時間的準備。先比較一組，再做下一處調整。

下次訓練保留一個重點

最後用最初那種發球結束桌球短發球練習，比較過網高度和對方桌面第二跳。把最有幫助的一項調整留到下次：可能是更穩定的準備、更低的球路，也可能是更可靠的長度。先有一顆自己能辨認、能重複的發球，再發展落點和變化。

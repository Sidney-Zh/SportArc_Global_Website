羽球反手發球練習：控制短球弧線，準備下一拍

用三個練習檢查反手短發球的接觸、過網高度與發球後的準備，讓每次調整都有可以比較的結果。

球剛過網還在往上飄，對手已經上前撲球，自己的球拍卻停在發球的位置。下一次想貼網，又直接掛網。越想壓低，動作越容易變成最後一刻突然戳一下。

羽球反手發球可以拆開練：先讓接觸能重複，再配合弧線與落點，最後接上下一拍的準備。這套練習適合正在學雙打短發球的球友，暫時不用加入偷發後場的變化。準備場地、幾顆羽球及明確的目標；練到回球銜接時，再請同伴加入。

先決定這球要去哪裡

發球必須進入斜對角的發球區。練短球時，讓球靠近網帶上方通過，落在短發球線之後、發球區前部的範圍。初學時先和邊線保持一點距離，不必每球壓線。

低弧線能減少對手直接進攻的空間，但不能保證回球一定容易。發完提拍、準備下一拍，也是這次練習的內容，不要只站著看球飛。

準備舒服，動作才好重複

使用放鬆的反手拇指握拍，球拍放在身前。持拍側腳略在前是常見站法，但不必硬套同一個肘部角度、胸前距離或固定腳位。站穩，並為小幅向前揮拍留下空間。

用手指拿住羽毛部分，讓球頭朝向拍線。短距離引拍後向前送，拍面略微朝上。擊球前放開球，拍線接觸時不能還捏著它，也不要在放手時用指頭扭球加轉。

短發球需要一點向上的分量來越過球網，但不需要突然挑一下。先找到能平順重複的動作，再調整高度。

高度用尺量，不用球筒猜

按照世界羽聯的標準發球條款，擊球瞬間整顆球必須低於場地上方1.15公尺；球拍先擊中球頭，向前的發球動作須持續完成。從發球開始到發出期間，兩腳都要有部分保持靜止並接觸地面，站在正確的發球區內，不碰界線。

需要高度參考時，使用尺測量，並在上限以下留出餘裕。球筒長度可能不同，堆疊起來不是準確的標尺。參賽前也要確認該賽事採用標準條款，還是特定類別的替代規則，不要混用。

練習一：重複同一種輕接觸

練習目標： 讓球離開拍線的狀態盡量一致。

  1. 選定一側發球區，瞄準斜對角區內較寬的範圍。
  2. 每次重新擺好舒服的握拍與持球位置。
  3. 先發五球，保持小引拍、平順向前送。
  4. 記下主要失誤：下網、冒高、太長或偏向一側。一次改一處，再試一組。

五球只是方便比較的小組數，不是規定的訓練量。出球忽高忽低，先看球頭位置是否一致、握拍是否提早捏緊。接觸還不穩定時，目標先維持寬鬆。

練習二：同時看過網高度與落點

練習目標： 壓低弧線，仍然到達有效發球區。

  1. 請同伴在場邊安全的位置看高度，自己觀察落點。
  2. 重複相同動作，暫時不瞄準短發球線的最邊緣。
  3. 球往上飄時，可減少向上挑的幅度，或小幅改變拍面；距離不足，則先看向前送的動作是否在接觸時停住。
  4. 比較下一組，再決定是否需要第二個調整。

下網不一定都靠加力解決，突然用力可能讓下一球又高又長。相反地，即使過網很低，卻落在短發球線之前，也沒有完成任務。

練習三：發完接一拍約定的回球

練習目標： 把發球與下一拍準備連起來。

  1. 請同伴正常站位接發，先約定容易處理的回球區域。
  2. 用相同準備發球，接著提拍，恢復平衡的預備姿勢。
  3. 接好這一拍就停，重新準備下一次發球。
  4. 能穩定銜接後，再讓同伴從兩種可控制的回球中選擇。

同伴是在協助練銜接，不是每球都要搶攻得分。若總來不及，先退回一種固定回球。雙打時，也和搭檔說好第一拍各自負責的範圍。

不穩定時先看哪裡

總是冒高： 看看球拍是否在接觸時突然上挑，或猶豫後又捏緊手戳出去。向前的動作保持小而連續。

總是下網： 先檢查拍面與球頭位置，再考慮力量。重新找穩定時，多留一些過網餘裕。

方向一直變： 比較接觸時的拍面朝向與準備動作。不要靠「打拍線某個角落，就一定往某邊走」的固定口訣判斷。

自己練可以，有人接就亂： 用練習三逐步加入接發者。雙方準備好後正常發球，保留熟悉的流程，不刻意拖延。

帶走一個能重複的調整

比較最後與最初的一組：合乎規則且落入目標的球有多少、弧線是否較一致、發完是否已提拍準備。選一個有效的調整，下次繼續使用，再逐漸增加速度或偷發後場的變化。
